# Daily carry-forward — human decision

The user requested moving incomplete work from the previous day into a newly
created daily note. For a tree containing completed and incomplete tasks, the
user explicitly chose to move the whole tree if any task is incomplete,
including its completed items. No additional rationale was supplied. The current
contract lives on the daily-log architecture page.
