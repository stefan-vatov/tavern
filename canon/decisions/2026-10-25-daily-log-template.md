# Daily log template — human decision

The user requested that explicit daily-log creation use Templater and the daily
note template. When asked where Tavern should find it, the user chose a template
file selected in Tavern settings. If Templater is unavailable or rendering fails,
the user chose to stop and show the error rather than create a basic note.
No additional rationale was supplied. The current contract lives on the daily-log
architecture page.
