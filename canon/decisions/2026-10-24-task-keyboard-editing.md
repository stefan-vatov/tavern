# Task keyboard editing — human decision

The user requested Ctrl+Enter to create a sibling, Shift+Enter to create a
nested subitem, and plain Enter to do nothing while editing a task. The supplied
reason was to make creating more items quick.

The user also requested removing empty rows on blur to keep the list tidy, and
explicitly chose to retain an empty parent's subitems by moving them up one
level. The current contract lives in the related task-editing page.
