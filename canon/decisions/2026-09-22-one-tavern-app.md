# One Obsidian-backed Tavern app

On 22 September 2026, the user requested Tavern as an Obsidian-backed app in a
new window and explicitly directed that it not be split into multiple apps.
All views will be developed inside the one Tavern app.

The supplied research described several separate app windows. The user's
explicit instruction selected one Tavern app instead. No further decision
rationale was supplied.

The active behavior is owned by the app-window architecture page.
