# Send project work to Captain's Log — human decision

The user requested the reverse of To Backlog: any project or global task/tree
can be sent to Captain's Log from its context menu, handling existing copies.
The user chose to keep the project task and add a linked daily copy. Choosing
any member of a tree sends its whole tree.

The user chose the day currently displayed in Captain's Log as the destination.
If that note is absent, the action stays disabled until **Create daily log** is
used. The user also chose to move an existing linked copy from the hidden Notes
section into visible Plan.

The active contract lives in the related task-transfer page.
