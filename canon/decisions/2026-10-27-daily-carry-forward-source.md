# Daily carry-forward source — human decision

The user requested finding the last day with tasks when creating a daily note,
because limiting carry-forward to yesterday fails when days pass between notes.
The current contract lives on the daily-log architecture page. The earlier
decision's choice to retain whole mixed task trees remains in effect.
