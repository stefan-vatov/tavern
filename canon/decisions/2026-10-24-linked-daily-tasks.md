# Linked daily tasks

On 24 October 2026, the user requested copying project tasks from the global
or focus queue into a daily log while retaining a reference between the copies.
Completing a daily copy must complete its project source, and completion of
the source must update the daily copy.

The user explicitly approved standard Obsidian block IDs on linked task lines
and synchronization of both checking and unchecking. No additional decision
rationale was supplied.

The active behavior is owned by the daily-log architecture page.
